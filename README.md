# Распределение памяти при возвратном дрейфе сетевого трафика

Исходники дипломной работы о распределении ограниченной памяти между
дообучением сетевого детектора и калибровкой порога тревоги.

## Структура

- `vkr.tex` — основной документ.
- `abstract.tex` — авторская аннотация (добавляется отдельным PR);
- `task.tex` — постановка задачи (добавляется отдельным PR).
- `related.tex`, `related.bib` — обзор и 21 источник (добавляются отдельным PR).
- `ugost2008ls.bst` — стиль библиографии из шаблона (добавляется с обзором).
- `preamble.tex` — настройки документа поверх класса шаблона.
- `matmex-diploma-custom.cls`, `pretitle.tex` — оформление.
- `pdf/abstract.pdf`, `pdf/task.pdf`, `pdf/related.pdf` — готовые PDF для
  проверки соответствующих разделов; добавляются вместе с их исходниками.

Аннотация, постановка задачи и обзор подключаются автоматически при наличии
файлов, поэтому каждый раздел можно собирать и проверять независимо.
Каждая сборка включает русский и английский титульные листы ВКР бакалавра;
их реквизиты находятся в `preamble.tex`. Рецензент пока не назначен.

## Ветки и проверка

Общие файлы шаблона находятся в ветке `thesis-base`, созданной от `main`.
От одного базового коммита `thesis-base` создаются три независимые ветки:

- `thesis-abstract` — `abstract.tex`, `pdf/abstract.pdf`.
- `thesis-task` — `task.tex`, `pdf/task.pdf`.
- `thesis-related` — `related.tex`, `related.bib`, `ugost2008ls.bst`,
  `pdf/related.pdf`.

У всех трёх PR целевая ветка — `thesis-base`. Их можно проверять одновременно
и объединять в произвольном порядке. После объединения всех трёх разделов
ветка `thesis-base` содержит общий документ, готовый к переносу в `main`.

Нумерация разделов автоматическая: в отдельной ветке обзор будет разделом 1,
а после добавления постановки задачи — разделом 2.

## Сборка

Основной файл — `vkr.tex`, компилятор — XeLaTeX. Нужны TeX Live с XeLaTeX,
русской локализацией и пакетами класса (включая `wrapfig2` и `minted`),
шрифты Computer Modern Unicode и `latexmk`:

```sh
make
```

Альтернатива с Tectonic (при первом запуске загружает недостающие TeX-пакеты):

```sh
make tectonic
```

Результат обоих способов — `build/vkr.pdf`. `make clean` удаляет
вспомогательные файлы сборки через `latexmk`, сохраняя PDF.

Каталог `pdf/` включается в Git: каждый PR содержит PDF своего раздела
с двумя титульными листами, оглавлением и, для обзора, библиографией.
Разные имена PDF позволяют объединять независимые PR без конфликта файлов.
В чистой ветке раздела выполните `make tectonic`, затем скопируйте
`build/vkr.pdf` в `pdf/abstract.pdf`, `pdf/task.pdf` или `pdf/related.pdf`.
Перед сборкой убедитесь, что рядом нет незакоммиченных TeX-файлов других
разделов: основной документ подключает все присутствующие разделы.
